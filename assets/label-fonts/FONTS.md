# Label fonts

The fonts `retail-print-kit/label-design` draws designer text with, so a label looks the same in every app that
renders it. Latin subsets as served by Google Fonts. Each family's licence text sits beside its files.

| Files | Family | Licence |
|---|---|---|
| `arimo-*.woff2` | Arimo | SIL Open Font License 1.1 (`arimo-OFL.txt`) |
| `archivo-narrow-*.woff2` | Archivo Narrow | SIL Open Font License 1.1 (`archivo-narrow-OFL.txt`) |
| `oswald-*.woff2` | Oswald | SIL Open Font License 1.1 (`oswald-OFL.txt`) |
| `roboto-slab-*.woff2` | Roboto Slab | Apache License 2.0 (`roboto-slab-LICENSE.txt`) |
